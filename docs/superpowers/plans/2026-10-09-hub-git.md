# Hub git Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the hub's git repository useful: cc-hub commits what its own commands change, the agent commits after each task, the nightly task pushes, `doctor` reports the repository's state, and `hub-adapt` registers the default scheduled tasks on every machine.

**Architecture:** A new module `src/cc_hub/gitops.py` wraps the git command line (path-limited commits, identity, status). `init`, `update` and `doctor --fix` call it; `doctor` gets a `git` check. Templates (`AGENTS.md`, `BOOTSTRAP.md`, `hub-adapt`, `hub-memory`, `cron/memory-consolidate.md`) carry the agent-side rules. This is plan 1 of 3 for 0.4.0; plans 2 (apps) and 3 (feedback and release) build on `gitops`.

**Tech Stack:** Python ≥ 3.11, typer, rich, tomli-w, pytest, the `git` executable (2.32+ in tests, for `GIT_CONFIG_GLOBAL`).

**Spec:** `docs/superpowers/specs/2026-09-22-cc-hub-design.md` (§3 rule 3, §4.1, §4.2, §4.5, §5.1 提交, §5.2, §5.3 `git`, §5.4, §6 `hub-memory`, §7 goal 4, §9).

## Global Constraints

- Every Python file starts with `# -*- coding: utf-8 -*-`; text IO uses `encoding="utf-8"`, writes use LF (`cc_hub.encoding.write_text`).
- Paths via `pathlib`; atomic writes via `write_text`.
- Templates are English, LF, no BOM; `AGENTS.md` ≤ 150 lines ending with the tail marker; each `SKILL.md` ≤ 100 lines with `name` equal to its directory.
- cc-hub commits only the paths it changed: `git commit -- <paths>`; messages start with `cc-hub: `.
- A failed commit is a warning, never a failed command; retry once when the index is locked.
- Repository-local identity when git has none: `user.name = "<hub name> (cc-hub)"`, `user.email = "hub@cc-hub.invalid"`.
- Docs and templates describe the current design; no "removed X" or history (CHANGELOG excepted).
- Ruff line length 100; run `ruff check .` and `pytest -q` before each commit.

Run tests with the project's environment. This machine has no `uv`; use a venv with `pip install -e . pytest ruff` (see the repository's CI for the uv equivalent: `uv run pytest -q`).

```python
# -*- coding: utf-8 -*-
"""The hub's own git repository: path-limited commits, identity, status."""

from __future__ import annotations

import os
import shutil
import subprocess
import time
from pathlib import Path

IDENTITY_EMAIL = "hub@cc-hub.invalid"
_INDEX_LOCK = "index.lock"


class GitError(Exception):
    pass


def git_available() -> bool:
    return shutil.which("git") is not None


def run_git(
    repo: Path, *args: str, check: bool = True, binary: bool = False
) -> subprocess.CompletedProcess:
    """Run `git -C <repo> <args>`; never waits for a credential prompt."""
    env = {**os.environ, "GIT_TERMINAL_PROMPT": "0"}
    text_mode = {} if binary else {"text": True, "encoding": "utf-8", "errors": "replace"}
    proc = subprocess.run(
        ["git", "-C", str(repo), *args], capture_output=True, env=env, **text_mode
    )
    if check and proc.returncode != 0:
        err = proc.stderr.decode("utf-8", "replace") if binary else proc.stderr
        raise GitError(err.strip() or f"git {args[0]} exited with {proc.returncode}")
    return proc


def is_repo(hub: Path) -> bool:
    return git_available() and (Path(hub) / ".git").exists()


def has_commits(hub: Path) -> bool:
    return run_git(hub, "rev-parse", "--verify", "-q", "HEAD", check=False).returncode == 0


def _config(hub: Path, key: str) -> str:
    return run_git(hub, "config", "--get", key, check=False).stdout.strip()


def has_identity(hub: Path) -> bool:
    return bool(_config(hub, "user.name") and _config(hub, "user.email"))


def ensure_identity(hub: Path, name: str) -> list[str]:
    """Set whatever part of user.name / user.email git lacks, in this repository only."""
    wanted = {"user.name": f"{name} (cc-hub)", "user.email": IDENTITY_EMAIL}
    set_keys = []
    for key, value in wanted.items():
        if not _config(hub, key):
            run_git(hub, "config", "--local", key, value)
            set_keys.append(key)
    return set_keys


def _committable(hub: Path, rel: str) -> bool:
    """Present or tracked, and not ignored."""
    if run_git(hub, "check-ignore", "-q", "--", rel, check=False).returncode == 0:
        return False
    if (Path(hub) / rel).exists():
        return True
    return bool(run_git(hub, "ls-files", "--", rel, check=False).stdout.strip())


def commit_paths(hub: Path, paths: list[str], message: str, *, wait: float = 0.5) -> str | None:
    """Commit exactly `paths` (relative to the hub); other changes stay as they are.

    Returns None when committed or when there was nothing to commit, otherwise a
    warning. Does nothing outside a git repository.
    """
    hub = Path(hub)
    if not is_repo(hub):
        return None
    rels = sorted({p for p in paths if _committable(hub, p)})
    if not rels:
        return None
    for attempt in (0, 1):
        try:
            run_git(hub, "add", "-A", "--", *rels)
            staged = run_git(hub, "diff", "--cached", "--quiet", "--", *rels, check=False)
            if staged.returncode == 0:
                return None
            run_git(hub, "commit", "-q", "-m", message, "--", *rels)
            return None
        except GitError as exc:
            if attempt == 0 and _INDEX_LOCK in str(exc):
                time.sleep(wait)
                continue
            return f"not committed: {exc}"
    return None


def commit_all(hub: Path, message: str) -> str | None:
    """Commit every file that is not ignored."""
    hub = Path(hub)
    if not is_repo(hub):
        return None
    try:
        run_git(hub, "add", "-A")
        if run_git(hub, "diff", "--cached", "--quiet", check=False).returncode == 0:
            return None
        run_git(hub, "commit", "-q", "-m", message)
    except GitError as exc:
        return f"not committed: {exc}"
    return None


def uncommitted(hub: Path) -> int:
    out = run_git(hub, "status", "--porcelain", check=False).stdout
    return len([line for line in out.splitlines() if line.strip()])


def remotes(hub: Path) -> list[str]:
    return run_git(hub, "remote", check=False).stdout.split()
```

def git_check(hub: Path) -> Check:
    if not gitops.git_available() or not (hub / ".git").exists():
        return Check(
            "git",
            "warn",
            "the hub is not a git repository: no history and no backup",
            f'install git, then run `cc-hub init "{hub}"`',
        )
    problems = []
    if not gitops.has_identity(hub):
        problems.append("no git identity (user.name, user.email)")
    n = gitops.uncommitted(hub)
    if n:
        problems.append(f"{n} uncommitted change(s)")
    names = gitops.remotes(hub)
    if not names:
        problems.append("no remote: the hub is not backed up")
    if problems:
        return Check(
            "git",
            "warn",
            "; ".join(problems),
            "the agent commits after each task; docs/backup.md sets up a private remote",
        )
    return _ok("git", "committed; remote: " + ", ".join(names))

```markdown
# Backing up the hub

The hub is a git repository. `cc-hub` commits what its own commands change,
and the agent commits after each task that changed files in the hub. Nothing
leaves the machine until you add a remote; from then on the nightly
memory-consolidate task pushes.

The hub holds `USER.md`, `MEMORY.md`, the daily logs and app data, so the
remote must be a **private** repository.

## Set up a remote

1. Create an empty private repository without a README, for example
   `you/my-hub` on GitHub.
2. On the machine that runs the hub, create a key that can write to that one
   repository:

       ssh-keygen -t ed25519 -f ~/.ssh/cc-hub-backup -N "" -C "cc-hub backup"

   Add `~/.ssh/cc-hub-backup.pub` to the repository as a deploy key with
   write access (GitHub: Settings → Deploy keys).
3. Point the hub at it and push once:

       git -C ~/.cc-hub remote add origin git@github.com:you/my-hub.git
       git -C ~/.cc-hub config core.sshCommand "ssh -i ~/.ssh/cc-hub-backup -o IdentitiesOnly=yes"
       git -C ~/.cc-hub push -u origin HEAD

`cc-hub doctor` stops reporting "no remote" once `origin` exists.

## When a push is rejected

A rejected push means the remote has commits this machine does not, usually
because the hub ran somewhere else too. The agent does not pull or merge; it
logs the rejection and reports it. Run the hub on one machine at a time, and
reconcile by hand with `git pull --rebase` or by choosing one side.
```
