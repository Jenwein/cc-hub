# cc-hub 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 cc-hub 收敛成 agent 的 workspace：CLI 只剩 `init`、`doctor`、`update`、`memory`、`link`、`where`、`version`，模板只剩人格、记忆、规程、skills、cron，`update` 保留 `AGENTS.md` 分界标记以下的内容，发布 0.3.0。

**Architecture:** 删除 `env`、`projects`、`hosts` 三个命令模块和它们的模板、skills、doctor 检查；`manifest.py` 新增 `KEEPS_TAIL` 与 `TAIL_MARKER`，`update.py` 新增 `merge_tail` 在覆盖 `AGENTS.md` 时接回尾部；模板和文档按规格重写。

**Tech Stack:** Python ≥ 3.11，typer，rich，tomli-w，pytest，ruff，uv，hatchling。

**Spec:** `docs/superpowers/specs/2026-09-22-cc-hub-design.md`（执行者先读规格，再读本计划）。

## Global Constraints

- Python `>=3.11`；运行时依赖只有 `typer>=0.12`、`rich>=13`、`tomli-w>=1.0`。
- 所有 `.py` 文件首行 `# -*- coding: utf-8 -*-`，UTF-8 无 BOM，LF 换行；ruff 行宽 100。
- 文件读写显式 `encoding="utf-8"`，路径用 `pathlib`。
- 框架拥有的模板用英文；`AGENTS.md` ≤ 150 行，最后一行是 `TAIL_MARKER`；每个 `SKILL.md` ≤ 100 行，frontmatter 的 `name` 等于目录名。
- 模板、文档、README、代码注释和测试只描述当前设计：不提已删除的功能，不写"为什么不做"之类的裁决或演变说明。版本历史只写进 `CHANGELOG.md`。产品里不出现项目注册或远程主机相关内容。
- 分界标记原文：`<!-- cc-hub: framework content ends here; everything below is kept by cc-hub update -->`；cc-connect 标记原文：`<!-- cc-connect-instructions -->`。
- 每个任务结束时全部测试通过、`ruff check .` 无报错，然后提交。提交信息用 conventional commits，并以空行加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` 结尾。
- 分支：`refactor/workspace-scope`（已存在，规格已提交在上面）。

- [ ] **Step 3: 重写 `src/cc_hub/commands/doctor.py`**

整份替换为：

```python
# -*- coding: utf-8 -*-
"""cc-hub doctor: health checks for a hub directory."""

from __future__ import annotations

import re
import shutil
import tomllib
from collections.abc import Callable
from dataclasses import asdict, dataclass
from pathlib import Path

import typer
from rich.markup import escape
from rich.table import Table

from cc_hub import __version__, manifest
from cc_hub.commands.init import enclosing_git_repo
from cc_hub.encoding import read_text, write_text
from cc_hub.hub import load_config
from cc_hub.platform import COPY_MARKER

Which = Callable[[str], "str | None"]


@dataclass
class Check:
    id: str
    status: str  # ok | warn | fail
    message: str
    fix: str = ""


DATE_NAME = re.compile(r"^\d{4}-\d{2}-\d{2}\.md$")
AGENT_MARKERS = {"claude": ("claude", ".claude"), "codex": ("codex", ".codex")}
# agent -> [(relative path, "exists" | "if-present-contains", needle)]
# A CLAUDE.md is optional (Claude Code reads AGENTS.md when there is none), but
# one without the import would shadow AGENTS.md.
POINTER_RULES: dict[str, list[tuple[str, str, str]]] = {
    "claude": [
        (".claude/skills", "exists", ""),
        ("CLAUDE.md", "if-present-contains", "@AGENTS.md"),
    ],
    "codex": [
        (".agents/skills", "exists", ""),
    ],
}
_READ_ERRORS = (OSError, UnicodeDecodeError, tomllib.TOMLDecodeError)


def detect_agents(*, home: Path, which: Which) -> list[str]:
    return [a for a, (exe, dot) in AGENT_MARKERS.items() if which(exe) or (home / dot).exists()]


def _ok(id_: str, message: str) -> Check:
    return Check(id_, "ok", message)


def run_checks(
    hub: Path,
    *,
    fix: bool = False,
    home: Path | None = None,
    which: Which = shutil.which,
    package_version: str = __version__,
) -> list[Check]:
    hub = Path(hub)
    home = home or Path.home()
    checks: list[Check] = []

    # hub-toml
    cfg: dict = {}
    try:
        cfg = load_config(hub)
        tv = str(cfg.get("hub", {}).get("template_version", "0"))
        if tv == package_version:
            checks.append(_ok("hub-toml", f"template_version {tv}"))
        else:
            checks.append(
                Check(
                    "hub-toml",
                    "warn",
                    f"template_version {tv}, package is {package_version}",
                    "run `cc-hub update` (read the migration notes in CHANGELOG.md first)",
                )
            )
    except _READ_ERRORS as exc:
        checks.append(
            Check("hub-toml", "fail", f"hub.toml unreadable: {exc}", "fix the TOML syntax")
        )
    name = str(cfg.get("hub", {}).get("name", hub.name))

    # required-files (fix: user files and .gitignore only)
    if fix:
        write_text(
            hub / ".gitignore", manifest.render(".gitignore", name=name, version=package_version)
        )
        for d in manifest.USER_DIRS:
            (hub / d).mkdir(exist_ok=True)
        for rel in manifest.USER_OWNED:
            if not (hub / rel).is_file():
                write_text(hub / rel, manifest.render(rel, name=name, version=package_version))
    missing = [
        rel
        for rel in manifest.FRAMEWORK_OWNED + manifest.USER_OWNED
        if rel not in manifest.ONE_TIME and not (hub / rel).is_file()
    ]
    if missing:
        checks.append(
            Check(
                "required-files",
                "fail",
                "missing: " + ", ".join(missing),
                "`cc-hub doctor --fix` restores user files; "
                "`cc-hub update` restores framework files",
            )
        )
    else:
        checks.append(_ok("required-files", "all present"))

    # bootstrap-pending
    if (hub / "BOOTSTRAP.md").exists():
        checks.append(
            Check(
                "bootstrap-pending",
                "warn",
                "BOOTSTRAP.md still present: first-run ritual not completed",
                "send the agent its first message",
            )
        )
    else:
        checks.append(_ok("bootstrap-pending", "bootstrap completed"))

    # memory-budget
    max_lines = int(cfg.get("memory", {}).get("max_lines", 200))
    for rel, limit in (("MEMORY.md", max_lines), ("USER.md", 100)):
        p = hub / rel
        if not p.is_file():
            continue
        try:
            n = len(read_text(p).splitlines())
        except _READ_ERRORS as exc:
            checks.append(
                Check(
                    f"memory-budget:{rel}",
                    "fail",
                    f"unreadable: {exc}",
                    "fix the file's permissions or re-save it as UTF-8",
                )
            )
            continue
        if n <= limit:
            checks.append(_ok(f"memory-budget:{rel}", f"{n}/{limit} lines"))
        else:
            checks.append(
                Check(
                    f"memory-budget:{rel}",
                    "fail",
                    f"{n}/{limit} lines",
                    "run the consolidation procedure from the hub-memory skill",
                )
            )

    # memory-files
    mem = hub / "memory"
    bad = [p.name for p in mem.glob("*.md") if not DATE_NAME.match(p.name)] if mem.is_dir() else []
    if bad:
        checks.append(
            Check(
                "memory-files",
                "warn",
                "unexpected names: " + ", ".join(bad),
                "rename to YYYY-MM-DD.md",
            )
        )
    else:
        checks.append(_ok("memory-files", "names ok"))

    # pointers
    agents = detect_agents(home=home, which=which)
    if not agents:
        checks.append(_ok("pointers", "no agent runtimes detected on this machine"))
    for agent in agents:
        rules = POINTER_RULES[agent]
        if not any((hub / rel).exists() for rel, _, _ in rules):
            checks.append(_ok(
                f"pointers:{agent}",
                "not set up here; the hub-adapt skill does it when this runtime runs here",
            ))
            continue
        problems = []
        for rel, kind, needle in rules:
            p = hub / rel
            if not p.exists():
                if kind == "exists":
                    problems.append(f"{rel} missing")
                continue
            if kind == "exists":
                continue
            try:
                found = needle in read_text(p)
            except _READ_ERRORS as exc:
                problems.append(f"{rel} unreadable: {exc}")
                continue
            if not found:
                problems.append(f"{rel} lacks '{needle}' and hides AGENTS.md")
        if problems:
            checks.append(
                Check(
                    f"pointers:{agent}",
                    "warn",
                    "; ".join(problems),
                    "run the hub-adapt skill from the agent",
                )
            )
        else:
            checks.append(_ok(f"pointers:{agent}", "pointers present"))

    # link-stale
    skills = hub / "skills"
    src_mtime = max((p.stat().st_mtime for p in skills.rglob("*") if p.is_file()), default=0.0)
    stale = [
        str(m.parent.relative_to(hub))
        for m in hub.glob(f".*/skills/{COPY_MARKER}")
        if m.stat().st_mtime < src_mtime
    ]
    if stale:
        checks.append(
            Check(
                "link-stale",
                "warn",
                "stale copies: " + ", ".join(stale),
                "re-run the hub-adapt skill (cc-hub link)",
            )
        )
    else:
        checks.append(_ok("link-stale", "no stale copies"))

    # nested-git
    repo = enclosing_git_repo(hub.parent)
    if repo is None:
        checks.append(_ok("nested-git", "hub is outside other repositories"))
    else:
        checks.append(
            Check(
                "nested-git",
                "fail",
                f"hub is inside {repo}",
                "move the hub outside that repository",
            )
        )

    return checks

CC_CONNECT_MARKER = "<!-- cc-connect-instructions -->"


def merge_tail(new_text: str, current: str) -> str:
    """Append to `new_text` the part of `current` that belongs to the user and cc-connect.

    That part is everything after manifest.TAIL_MARKER. A file without the marker
    keeps cc-connect's instructions block, from CC_CONNECT_MARKER to the end.
    """
    if manifest.TAIL_MARKER in current:
        tail = current.split(manifest.TAIL_MARKER, 1)[1]
        return new_text + tail.removeprefix("\n")
    if CC_CONNECT_MARKER in current:
        return new_text + "\n" + current[current.index(CC_CONNECT_MARKER):]
    return new_text
```

## Requirements

From PyPI:

Or a released tag straight from GitHub:

    uv tool install git+https://github.com/Jenwein/cc-hub.git@v0.3.0

Or download the wheel attached to the GitHub release and install that file:

    uv tool install ./cc_hub-0.3.0-py3-none-any.whl

`uv tool install` puts `cc-hub` in `~/.local/bin` (Windows: `%USERPROFILE%\.local\bin`).
Make sure that directory is on your PATH; `uv tool update-shell` can add it.

**Install from a regular terminal** (Windows Terminal, PowerShell, a Linux or
macOS shell). On Windows, a shell running inside the Claude desktop app is part
of a packaged (MSIX) app: new folders it creates under `%APPDATA%` go to the
app's private storage, so a cc-hub installed there is invisible to cc-connect
and to the agents it starts. The symptom is `uv trampoline failed to
canonicalize script path`; reinstall from a regular terminal.

working directory.

# Windows notes

## Recommended: WSL2

Run cc-connect, the agent CLIs and the hub inside WSL2. Keep the hub on the
Linux filesystem (`~/.cc-hub`), not under `/mnt/c`, which is slow and has
different permission semantics. Everything in this project behaves as on Linux.

## Native Windows

cc-hub works natively, with these differences:

- **Where to install.** Install cc-hub from a regular terminal, not from a
  shell inside the Claude desktop app. That app is packaged (MSIX), and new
  folders its shells create under `%APPDATA%` land in its private storage,
  where cc-connect and the agents it starts cannot see them.
- **Links.** Creating symlinks needs Developer Mode or administrator rights,
  so `cc-hub link` creates a directory junction instead; if that fails it
  copies and leaves a `.cc-hub-copied` marker. `cc-hub doctor` reports
  `link-stale` when the copy is older than `skills/`; re-run the `hub-adapt`
  skill to refresh it.
- **Shell.** Claude Code uses Git Bash for its Bash tool when Git for Windows
  is installed and PowerShell otherwise; Codex uses PowerShell.
- **Encoding.** All cc-hub output is UTF-8.
- **Line endings.** Keep hub files LF. Some skill loaders silently drop
  frontmatter when a `SKILL.md` has CRLF endings.
- **Paths.** The hub defaults to `%USERPROFILE%\.cc-hub`.
