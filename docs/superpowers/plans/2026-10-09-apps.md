# Apps and Taps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a hub install apps (skills + scheduled tasks + setup steps + data skeleton) from taps (git repositories), with two-step install/update/remove, per-machine setup state, and restore on a new machine.

**Architecture:** Three new modules. `applock.py` reads and writes `apps.lock`. `taps.py` is git plumbing for taps (clone, fetch, resolve, list and read files at a commit, diffs). `apps.py` holds `app.toml` parsing and validation, install/update/remove/sync, setup state and status. `commands/tap.py` and `commands/app.py` are thin CLIs over `apps.py`. `link.py` learns about app skills, `doctor` gets an `apps` check, and templates gain the `hub-apps` skill. cc-hub never executes anything an app provides.

**Tech Stack:** Python ≥ 3.11, typer, rich, tomli-w, pytest, git ≥ 2.32.

**Spec:** `docs/superpowers/specs/2026-09-22-cc-hub-design.md` (§3, §4.1, §4.5, §5.1, §5.3 `apps`, §5.6, §5.7, §5.8, §7 goals 2 and 4, §8, §9, §12, §13, §14).

**Depends on:** plan 1 (`docs/superpowers/plans/2026-10-09-hub-git.md`): `cc_hub.gitops` (`run_git`, `GitError`, `commit_paths`) and the test fixtures `git_env`, `git_hub` in `tests/conftest.py`.

## Global Constraints

- Every Python file starts with `# -*- coding: utf-8 -*-`; text IO is UTF-8; writes go through `cc_hub.encoding.write_text` (atomic, LF). App files are copied as raw bytes, never converted.
- cc-hub never executes a string an app provides; requirements are checked with `shutil.which(bin)` only.
- Names of apps, skills, cron tasks and taps: `^[a-z0-9][a-z0-9-]{0,63}$`; skill names additionally must not start with `hub-`.
- Data dirs: relative, forward slashes, no `..`, first component not starting with `.` and not reserved (hub templates, `memory`, `scripts`, `apps`, `apps.lock`, `secrets`, `CLAUDE.md`, case-insensitive); no overlap between apps.
- An app in a tap is a top-level directory with `app.toml`; its name equals the directory name.
- Install, update and remove act only with `--yes`; without it they print and change nothing. The confirm command pins the commit (`--ref <full sha>`).
- `apps/` is gitignored; `apps.lock` is committed. Commands commit only their own paths, messages `cc-hub: tap add <name>`, `cc-hub: tap remove <name>`, `cc-hub: app install <name> (<tap>@<sha7>)`, `cc-hub: app update <name> (<old7>..<new7>)`, `cc-hub: app remove <name>`. `app sync` and `app setup-state` do not commit.
- Setup state lives in `.cc-hub/apps-state.toml` (not committed). Fingerprint = SHA-256 over `SETUP.md`, the `requires` of `app.toml`, and every `cron/*.md`.
- One `tap`/`app` command changes a hub at a time: lock file `.cc-hub/op.lock`, stale after 600 s.
- Agent-facing output is plain text; queries take `--json`; errors go to stderr with exit code 1.
- Ruff line length 100; `ruff check .` and `pytest -q` pass before each commit (`ruff check --fix .` sorts imports).

```python
# -*- coding: utf-8 -*-
"""apps.lock: the taps a hub has registered and the apps it has installed."""

from __future__ import annotations

import tomllib
from dataclasses import dataclass, field
from pathlib import Path

import tomli_w

from cc_hub.encoding import read_text, write_text

LOCK_FILE = "apps.lock"
_HEADER = "# Written by `cc-hub tap` and `cc-hub app`; change it with those commands.\n"


class LockError(Exception):
    pass


@dataclass
class Lock:
    taps: dict[str, dict] = field(default_factory=dict)
    apps: dict[str, dict] = field(default_factory=dict)


def load_lock(hub: Path) -> Lock:
    path = Path(hub) / LOCK_FILE
    if not path.is_file():
        return Lock()
    try:
        data = tomllib.loads(read_text(path))
    except (OSError, UnicodeDecodeError, tomllib.TOMLDecodeError) as exc:
        raise LockError(f"{LOCK_FILE} unreadable: {exc}") from exc
    return Lock(taps=dict(data.get("taps", {})), apps=dict(data.get("apps", {})))


def save_lock(hub: Path, lock: Lock) -> None:
    text = tomli_w.dumps({"taps": lock.taps, "apps": lock.apps})
    write_text(Path(hub) / LOCK_FILE, _HEADER + text)


def to_tilde(path: Path, *, home: Path | None = None) -> str:
    """`~/...` for a path under the home directory, so the lock works on another machine."""
    path = Path(path).expanduser().absolute()
    home = (home or Path.home()).absolute()
    try:
        return "~/" + path.relative_to(home).as_posix()
    except ValueError:
        return path.as_posix()


def from_tilde(text: str, *, home: Path | None = None) -> Path:
    if text == "~" or text.startswith("~/"):
        return (home or Path.home()) / text[2:]
    return Path(text)
```

```python
def rmtree(path: Path) -> None:
    """shutil.rmtree that also removes read-only files, such as git objects on Windows."""

    def _retry(func, failed, *_):
        os.chmod(failed, stat.S_IWRITE)
        func(failed)

    if sys.version_info >= (3, 12):
        shutil.rmtree(path, onexc=_retry)
    else:
        shutil.rmtree(path, onerror=_retry)
```

```python
def _git(root: Path, *args: str) -> str:
    return subprocess.run(
        ["git", "-C", str(root), *args], capture_output=True, text=True,

def _write_and_commit(root: Path, files: dict[str, str], remove, message: str) -> str:

        (root / rel).unlink()
    _git(root, "add", "-A")
    _git(root, "commit", "-q", "-m", message)
```

```python
# -*- coding: utf-8 -*-
"""Taps: git repositories holding apps, one top-level directory per app."""

from __future__ import annotations

import hashlib
import re
from dataclasses import dataclass
from pathlib import Path
from urllib.parse import urlsplit, urlunsplit

from cc_hub.applock import from_tilde, to_tilde
from cc_hub.gitops import GitError, run_git
from cc_hub.platform import rmtree

SHORTHAND = re.compile(r"^[A-Za-z0-9][A-Za-z0-9-]*/[A-Za-z0-9._-]+$")
SCP_LIKE = re.compile(r"^[A-Za-z0-9._-]+@[A-Za-z0-9.-]+:(?!//)")
GITHUB = re.compile(
    r"^(?:https://github\.com/|ssh://git@github\.com/|git@github\.com:)"
    r"(?P<repo>[A-Za-z0-9-]+/[A-Za-z0-9._-]+?)(?:\.git)?/?$"
)
APP_TOML = re.compile(r"[^/]+/app\.toml")


class TapError(Exception):
    pass


@dataclass
class TreeEntry:
    mode: str  # 100644, 100755, 120000 (symlink), 160000 (submodule)
    kind: str  # blob, or commit for a submodule
    sha: str
    path: str  # relative to the app directory


def is_url(source: str) -> bool:
    return "://" in source or bool(SCP_LIKE.match(source))


def normalize_source(source: str, *, cwd: Path | None = None) -> dict:
    """The apps.lock entry for a tap: {"url": ...} or {"path": "~/..."}."""
    if is_url(source):
        return {"url": source}
    local = Path(source).expanduser()
    if not local.is_absolute():
        local = (cwd or Path.cwd()) / local
    if local.exists():
        if not (local / ".git").exists():
            raise TapError(f"{local} is not a git repository")
        return {"path": to_tilde(local)}
    if SHORTHAND.match(source):
        return {"url": f"https://github.com/{source}"}
    raise TapError(f"{source}: not a git URL, an existing repository, or owner/repo on GitHub")


def default_name(entry: dict) -> str:
    raw = (entry.get("url") or entry["path"]).rstrip("/")
    return re.split(r"[/:]", raw)[-1].removesuffix(".git").lower()


def strip_credentials(url: str) -> str:
    parts = urlsplit(url)
    if parts.scheme in ("http", "https") and "@" in parts.netloc:
        return urlunsplit(parts._replace(netloc=parts.netloc.rsplit("@", 1)[1]))
    return url


def github_repo(url: str) -> str | None:
    """`owner/repo` for a GitHub https or ssh URL, else None."""
    m = GITHUB.match(strip_credentials(url))
    return m.group("repo") if m else None


def describe(entry: dict) -> str:
    return strip_credentials(entry["url"]) if "url" in entry else entry["path"]


def clone_dir(hub: Path, name: str) -> Path:
    return Path(hub) / ".cc-hub" / "taps" / name


def repo_path(hub: Path, name: str, entry: dict) -> Path:
    return from_tilde(entry["path"]) if "path" in entry else clone_dir(hub, name)


def default_ref(entry: dict) -> str:
    return "HEAD" if "path" in entry else "origin/HEAD"


def _safe(exc: Exception, url: str) -> str:
    return str(exc).replace(url, strip_credentials(url))


def clone(url: str, dest: Path) -> None:
    dest = Path(dest)
    if dest.exists():
        rmtree(dest)
    dest.parent.mkdir(parents=True, exist_ok=True)
    try:
        run_git(dest.parent, "clone", "-q", "--no-recurse-submodules", "--", url, str(dest))
    except GitError as exc:
        raise TapError(f"could not clone {strip_credentials(url)}: {_safe(exc, url)}") from None


def fetch(repo: Path, url: str) -> None:
    try:
        run_git(repo, "fetch", "-q", "--prune", "origin")
    except GitError as exc:
        raise TapError(f"could not fetch {strip_credentials(url)}: {_safe(exc, url)}") from None
    run_git(repo, "remote", "set-head", "origin", "--auto", check=False)


def resolve(repo: Path, ref: str) -> str:
    for candidate in (ref, f"origin/{ref}"):
        proc = run_git(
            repo, "rev-parse", "--verify", "-q", f"{candidate}^{{commit}}", check=False
        )
        if proc.returncode == 0:
            return proc.stdout.strip()
    raise TapError(f"{ref}: no such commit, tag or branch in the tap")


def has_commit(repo: Path, sha: str) -> bool:
    return run_git(repo, "cat-file", "-e", f"{sha}^{{commit}}", check=False).returncode == 0


def list_apps(repo: Path, commit: str) -> list[str]:
    out = run_git(repo, "ls-tree", "-r", "-z", "--name-only", commit).stdout
    return sorted(p.split("/")[0] for p in out.split("\0") if APP_TOML.fullmatch(p))


def ls_app(repo: Path, commit: str, app: str) -> list[TreeEntry]:
    out = run_git(repo, "ls-tree", "-r", "-z", "--full-tree", commit, "--", f"{app}/").stdout
    entries = []
    for record in filter(None, out.split("\0")):
        meta, path = record.split("\t", 1)
        mode, kind, sha = meta.split()
        entries.append(TreeEntry(mode, kind, sha, path[len(app) + 1 :]))
    if not any(e.path == "app.toml" for e in entries):
        raise TapError(f"{app}: no such app at {commit[:7]}")
    return entries


def read_blob(repo: Path, obj: str) -> bytes:
    """Raw bytes of a blob, by sha or `<commit>:<path>`; no line-ending conversion."""
    return run_git(repo, "cat-file", "blob", obj, binary=True).stdout


def blob_sha(data: bytes) -> str:
    return hashlib.sha1(b"blob %d\0" % len(data) + data).hexdigest()


def changed_files(repo: Path, old: str, new: str, app: str) -> list[tuple[str, str]]:
    out = run_git(
        repo, "diff", "--name-status", "-z", "--no-renames", old, new, "--", f"{app}/"
    ).stdout
    parts = [p for p in out.split("\0") if p]
    return [(parts[i], parts[i + 1][len(app) + 1 :]) for i in range(0, len(parts), 2)]


def diff_text(repo: Path, old: str, new: str, app: str, rels: list[str]) -> str:
    if not rels:
        return ""
    paths = [f"{app}/{rel}" for rel in rels]
    return run_git(repo, "diff", "--no-color", "--no-renames", old, new, "--", *paths).stdout
```

```python
# -*- coding: utf-8 -*-
"""Apps: app.toml, installing from taps, setup state, update, remove and sync."""

from __future__ import annotations

import re
import sys
import tomllib
from dataclasses import dataclass, field
from pathlib import PurePosixPath

from cc_hub import manifest
from cc_hub.applock import LOCK_FILE

NAME = re.compile(r"^[a-z0-9][a-z0-9-]{0,63}$")
VERSION = re.compile(r"^\d+(?:\.\d+){0,2}$")
CRON = re.compile(r"^---\n(?P<head>.*?)\n---\n(?P<body>.*)$", re.S)
NAME_RULE = (
    "lowercase letters, digits and hyphens, starting with a letter or digit, "
    "at most 64 characters"
)


class AppError(Exception):
    pass


def check_name(name: str, what: str, *, skill: bool = False) -> str:
    if not NAME.match(name) or (skill and name.startswith("hub-")):
        rule = NAME_RULE + (", not starting with 'hub-'" if skill else "")
        raise AppError(f"{what} {name!r}: use {rule}")
    return name


def version_tuple(text: str) -> tuple[int, int, int]:
    if not VERSION.match(text):
        raise AppError(f"{text!r} is not a version like 0.4.0")
    parts = [int(p) for p in text.split(".")] + [0, 0]
    return (parts[0], parts[1], parts[2])


def platform_key() -> str:
    if sys.platform.startswith("win"):
        return "windows"
    return "macos" if sys.platform == "darwin" else "linux"


@dataclass
class Requirement:
    name: str
    bin: str
    install: str | dict[str, str] | None = None

    def install_line(self, platform: str | None = None) -> str | None:
        if isinstance(self.install, dict):
            return self.install.get(platform or platform_key())
        return self.install


@dataclass
class AppManifest:
    name: str
    version: str
    description: str
    min_hub: str | None = None
    issues: str | None = None
    data_dirs: list[str] = field(default_factory=list)
    requires: list[Requirement] = field(default_factory=list)


def reserved_names() -> set[str]:
    firsts = {rel.split("/")[0] for rel in manifest.all_templates()}
    extra = {*manifest.USER_DIRS, "apps", LOCK_FILE, "secrets", "CLAUDE.md"}
    return {name.casefold() for name in firsts | extra}


def normalize_data_dir(raw: str) -> str:
    path = PurePosixPath(raw)
    if (
        not raw
        or "\\" in raw
        or re.search(r'[:*?"<>|]', raw)
        or path.is_absolute()
        or any(part in ("", ".", "..") for part in raw.split("/"))
    ):
        raise AppError(f"data dir {raw!r}: use a relative path inside the hub, with / separators")
    first = path.parts[0]
    if first.startswith(".") or first.casefold() in reserved_names():
        raise AppError(f"data dir {raw!r}: {first!r} belongs to the hub itself")
    return path.as_posix()


def _parts(rel: str) -> tuple[str, ...]:
    return PurePosixPath(rel.casefold()).parts


def overlaps(a: str, b: str) -> bool:
    pa, pb = _parts(a), _parts(b)
    n = min(len(pa), len(pb))
    return pa[:n] == pb[:n]


def inside(rel: str, directory: str) -> bool:
    pr, pd = _parts(rel), _parts(directory)
    return len(pr) > len(pd) and pr[: len(pd)] == pd


def check_entry_path(rel: str) -> None:
    parts = rel.split("/")
    if "\\" in rel or ":" in rel or any(p in ("", ".", "..", ".git") for p in parts):
        raise AppError(f"unsafe path in the app: {rel!r}")


def parse_manifest(text: str, *, dirname: str) -> AppManifest:
    where = f"{dirname}/app.toml"
    try:
        data = tomllib.loads(text)
    except tomllib.TOMLDecodeError as exc:
        raise AppError(f"{where}: {exc}") from exc
    app = data.get("app")
    if not isinstance(app, dict):
        raise AppError(f"{where}: missing [app] table")
    for key in ("name", "version", "description"):
        if not isinstance(app.get(key), str) or not app[key].strip():
            raise AppError(f"{where}: [app] {key} is required")
    if app["name"] != dirname:
        raise AppError(f"{where}: name {app['name']!r} must equal the directory name {dirname!r}")
    check_name(app["name"], "app name")
    min_hub = app.get("min_hub")
    if min_hub is not None:
        version_tuple(str(min_hub))
    dirs = data.get("data", {}).get("dirs", [])
    if not isinstance(dirs, list) or not all(isinstance(d, str) for d in dirs):
        raise AppError(f"{where}: [data] dirs must be a list of paths")
    requires = []
    for item in data.get("requires", []):
        if not (
            isinstance(item, dict)
            and isinstance(item.get("name"), str)
            and isinstance(item.get("bin"), str)
        ):
            raise AppError(f"{where}: every [[requires]] needs name and bin")
        install = item.get("install")
        if install is not None and not isinstance(install, (str, dict)):
            raise AppError(f"{where}: install of {item['name']} must be a string or a table")
        requires.append(Requirement(item["name"], item["bin"], install))
    data_dirs = [normalize_data_dir(d) for d in dirs]
    for i, a in enumerate(data_dirs):
        for b in data_dirs[i + 1 :]:
            if overlaps(a, b):
                raise AppError(f"{where}: data dirs {a!r} and {b!r} overlap")
    issues = app.get("issues")
    return AppManifest(
        name=app["name"],
        version=app["version"],
        description=app["description"].strip(),
        min_hub=str(min_hub) if min_hub is not None else None,
        issues=issues if isinstance(issues, str) else None,
        data_dirs=data_dirs,
        requires=requires,
    )


def parse_cron(text: str, *, where: str) -> dict:
    m = CRON.match(text.replace("\r\n", "\n"))
    if not m:
        raise AppError(f"{where}: needs a frontmatter block between --- lines")
    fields: dict[str, str] = {}
    for line in m.group("head").splitlines():
        key, sep, value = line.partition(":")
        if sep:
            fields[key.strip()] = value.split("#", 1)[0].strip().strip('"')
    if not fields.get("schedule"):
        raise AppError(f"{where}: schedule is required")
    return {
        "schedule": fields["schedule"],
        "default": fields.get("default", "false") == "true",
        "session": fields.get("session", "reuse"),
    }
```

```python
class GitSource:
    """An app at a commit of a tap."""

    def __init__(self, tap: str, repo: Path, commit: str, app: str) -> None:
        self.tap, self.repo, self.commit, self.app = tap, Path(repo), commit, app
        self.entries = taps.ls_app(self.repo, commit, app)
        self._sha = {e.path: e.sha for e in self.entries}

    def paths(self) -> list[str]:
        return sorted(self._sha)

    def read(self, rel: str) -> bytes:
        return taps.read_blob(self.repo, self._sha[rel])

    def validate(self) -> None:
        for e in self.entries:
            if e.kind != "blob" or e.mode == "120000":
                raise AppError(
                    f"{self.app}/{e.path}: only regular files are allowed "
                    "(no symlinks or submodules)"
                )
            check_entry_path(e.path)

    def write_to(self, dest: Path) -> None:
        for e in self.entries:
            target = dest / e.path
            target.parent.mkdir(parents=True, exist_ok=True)
            target.write_bytes(taps.read_blob(self.repo, e.sha))
            if e.mode == "100755" and not is_windows():
                target.chmod(target.stat().st_mode | 0o111)

    def describe(self) -> str:
        return f"{self.tap}@{self.commit[:7]}"


class DirSource:
    """An app in a local directory, linked rather than copied."""

    def __init__(self, root: Path) -> None:
        self.root = Path(root).expanduser().absolute()
        if not (self.root / "app.toml").is_file():
            raise AppError(f"{self.root}: no app.toml")
        self.app = self.root.name

    def paths(self) -> list[str]:
        out = []
        for p in self.root.rglob("*"):
            rel = p.relative_to(self.root)
            if p.is_file() and ".git" not in rel.parts:
                out.append(rel.as_posix())
        return sorted(out)

    def read(self, rel: str) -> bytes:
        return (self.root / rel).read_bytes()

    def validate(self) -> None:
        """The user's own working copy is linked as it is."""

    def describe(self) -> str:
        return f"link {to_tilde(self.root)}"


@dataclass
class AppPlan:

    source: GitSource | DirSource

    crons: dict[str, dict]

def read_installed(hub: Path, name: str) -> AppManifest | None:
    try:
        return parse_manifest(read_text(Path(hub) / "apps" / name / "app.toml"), dirname=name)
    except (OSError, UnicodeDecodeError, AppError):
        return None


def _installed_skills(hub: Path, lock: Lock, *, exclude: str) -> set[str]:
    hub = Path(hub)
    roots = [hub / "skills"] + [hub / "apps" / a / "skills" for a in lock.apps if a != exclude]
    return {
        p.name
        for root in roots
        if root.is_dir()
        for p in root.iterdir()
        if (p / "SKILL.md").is_file()
    }


def build_plan(hub: Path, lock: Lock, source, *, replacing: str | None = None) -> AppPlan:
    source.validate()
    paths = source.paths()
    try:
        text = source.read("app.toml").decode("utf-8")
    except UnicodeDecodeError as exc:
        raise AppError(f"{source.app}/app.toml is not UTF-8") from exc
    m = parse_manifest(text, dirname=source.app)
    if m.min_hub and version_tuple(__version__) < version_tuple(m.min_hub):
        raise AppError(f"{m.name} needs cc-hub {m.min_hub} or newer; run `uv tool upgrade cc-hub`")
    if replacing is None and m.name in lock.apps:
        raise AppError(f"{m.name} is already installed; use `cc-hub app update {m.name}`")
    skills = sorted({p.split("/")[1] for p in paths if re.fullmatch(r"skills/[^/]+/SKILL\.md", p)})
    for skill in skills:
        check_name(skill, "skill name", skill=True)
    clash = sorted(set(skills) & _installed_skills(hub, lock, exclude=m.name))
    if clash:
        raise AppError(f"skill name already used in this hub: {', '.join(clash)}")
    for other in lock.apps:
        theirs = read_installed(hub, other) if other != m.name else None
        for mine in m.data_dirs:
            for dir_ in theirs.data_dirs if theirs else []:
                if overlaps(mine, dir_):
                    raise AppError(f"data dir {mine!r} overlaps {dir_!r} of {other}")
    seed = []
    for p in paths:
        if p.startswith("seed/"):
            rel = p[len("seed/") :]
            if not any(inside(rel, d) for d in m.data_dirs):
                raise AppError(f"{m.name}/seed/{rel}: not inside a data dir declared in app.toml")
            seed.append(rel)
    crons = {}
    for p in paths:
        if re.fullmatch(r"cron/[^/]+\.md", p):
            task = p[len("cron/") : -len(".md")]
            check_name(task, "cron task")
            crons[task] = parse_cron(source.read(p).decode("utf-8"), where=f"{m.name}/{p}")
    scripts = [p for p in paths if p.startswith("scripts/")]
    return AppPlan(
        m, source, skills, crons, scripts, seed, "SETUP.md" in paths, "REMOVE.md" in paths
    )


def tap_source(
    hub: Path, lock: Lock, tap: str, app: str, ref: str | None, *, fetch: bool
) -> GitSource:
    entry = lock.taps.get(tap)
    if entry is None:
        raise AppError(f"no tap named {tap!r}; add it with `cc-hub tap add`")
    repo = taps.repo_path(hub, tap, entry)
    if "url" in entry:
        if not repo.exists():
            taps.clone(entry["url"], repo)
        elif fetch:
            taps.fetch(repo, entry["url"])
    elif not repo.exists():
        raise AppError(f"tap {tap}: {entry['path']} does not exist")
    commit = taps.resolve(repo, ref or taps.default_ref(entry))
    return GitSource(tap, repo, commit, app)


def plan_install(
    hub: Path, spec: str, *, ref: str | None = None, link: bool = False, fetch: bool = True
) -> AppPlan:
    hub = Path(hub)
    lock = load_lock(hub)
    if link:
        return build_plan(hub, lock, DirSource(Path(spec)))
    tap, sep, app = spec.partition("/")
    if not sep or not tap or not app or "/" in app:
        raise AppError(f"{spec}: name an app as <tap>/<app>, or pass a directory with --link")
    return build_plan(hub, lock, tap_source(hub, lock, tap, app, ref, fetch=fetch))


@contextmanager
def hub_lock(hub: Path, *, stale_after: float = 600.0) -> Iterator[None]:
    """One tap or app command changes a hub at a time."""
    path = Path(hub) / ".cc-hub" / "op.lock"
    path.parent.mkdir(parents=True, exist_ok=True)
    fd = None
    for attempt in (0, 1):
        try:
            fd = os.open(path, os.O_CREAT | os.O_EXCL | os.O_WRONLY)
            break
        except FileExistsError:
            try:
                stale = time.time() - path.stat().st_mtime > stale_after
            except OSError:
                stale = True
            if attempt == 0 and stale:
                path.unlink(missing_ok=True)
                continue
            raise AppError(
                "another cc-hub tap or app command is changing this hub; try again shortly"
            ) from None
    try:
        os.write(fd, str(os.getpid()).encode())
        os.close(fd)
        yield
    finally:
        path.unlink(missing_ok=True)


@dataclass
class InstallResult:
    name: str
    version: str
    source: str
    seeded: list[str] = field(default_factory=list)
    missing: list[Requirement] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)


def _staging(hub: Path, name: str) -> Path:
    path = Path(hub) / ".cc-hub" / "tmp" / f"{name}-{uuid.uuid4().hex[:8]}"
    path.parent.mkdir(parents=True, exist_ok=True)
    return path


def _materialize(hub: Path, source: GitSource, dest: Path) -> None:
    """Write the app to a temporary directory, then move it to `dest` in one step."""
    source.validate()
    staging = _staging(hub, source.app)
    try:
        source.write_to(staging)
        os.rename(staging, dest)
    finally:
        if staging.exists():
            rmtree(staging)


def _seed(hub: Path, plan: AppPlan, only: set[str] | None = None) -> list[str]:
    hub = Path(hub)
    for d in plan.manifest.data_dirs:
        (hub / d).mkdir(parents=True, exist_ok=True)
    seeded = []
    for rel in plan.seed:
        dst = hub / rel
        if (only is not None and rel not in only) or dst.exists():
            continue
        dst.parent.mkdir(parents=True, exist_ok=True)
        dst.write_bytes(plan.source.read(f"seed/{rel}"))
        seeded.append(rel)
    return seeded


def relink(hub: Path) -> list[str]:
    """Run `cc-hub link` again for every agent skills directory the hub has."""
    warnings = []
    for _, skills_dir in POINTERS.values():
        target = Path(hub) / skills_dir
        if not target.is_dir():
            continue
        try:
            for name, status in sync_skill_links(hub, target):
                if status == "blocked":
                    warnings.append(f"{skills_dir}/{name}: something else has this name")
        except LinkError as exc:
            warnings.append(str(exc))
    return warnings


def missing_requirements(m: AppManifest, which=shutil.which) -> list[Requirement]:
    return [r for r in m.requires if which(r.bin) is None]


def install(hub: Path, plan: AppPlan) -> InstallResult:
    hub = Path(hub)
    m, source = plan.manifest, plan.source
    with hub_lock(hub):
        lock = load_lock(hub)
        if m.name in lock.apps:
            raise AppError(f"{m.name} is already installed")
        dest = hub / "apps" / m.name
        if os.path.lexists(dest):
            raise AppError(f"{dest} exists but is not in apps.lock; move it away first")
        dest.parent.mkdir(exist_ok=True)
        if isinstance(source, DirSource):
            link_dir(source.root, dest)
            lock.apps[m.name] = {"link": to_tilde(source.root), "version": m.version}
        else:
            _materialize(hub, source, dest)
            lock.apps[m.name] = {"tap": source.tap, "commit": source.commit, "version": m.version}
        seeded = _seed(hub, plan)
        save_lock(hub, lock)
        warnings = relink(hub)
        warning = gitops.commit_paths(
            hub, [LOCK_FILE, *seeded], f"cc-hub: app install {m.name} ({source.describe()})"
        )
    return InstallResult(
        m.name, m.version, source.describe(), seeded, missing_requirements(m),
        warnings + ([warning] if warning else []),
    )


def load_state(hub: Path) -> dict:
    path = Path(hub) / STATE_FILE
    if not path.is_file():
        return {}
    try:
        return tomllib.loads(read_text(path))
    except (OSError, UnicodeDecodeError, tomllib.TOMLDecodeError):
        return {}


def save_state(hub: Path, state: dict) -> None:
    write_text(Path(hub) / STATE_FILE, tomli_w.dumps(state))


def fingerprint(app_dir: Path) -> str:
    """Hash of what setup depends on: SETUP.md, the requires of app.toml, the cron tasks."""
    h = hashlib.sha256()
    setup = app_dir / "SETUP.md"
    h.update(b"setup\0" + (setup.read_bytes() if setup.is_file() else b""))
    requires = tomllib.loads(read_text(app_dir / "app.toml")).get("requires", [])
    h.update(b"requires\0" + json.dumps(requires, sort_keys=True).encode("utf-8"))
    cron = app_dir / "cron"
    for p in sorted(cron.glob("*.md")) if cron.is_dir() else []:
        h.update(b"cron\0" + p.name.encode("utf-8") + b"\0" + p.read_bytes())
    return h.hexdigest()


def setup_status(hub: Path, name: str) -> tuple[str, str]:
    """(pending | waiting | done, note) for an installed app on this machine."""
    entry = load_state(hub).get(name)
    try:
        current = fingerprint(Path(hub) / "apps" / name)
    except (OSError, UnicodeDecodeError, tomllib.TOMLDecodeError):
        return "pending", ""
    if not entry or entry.get("fingerprint") != current:
        return "pending", ""
    return entry.get("state", "pending"), entry.get("note", "")


def set_setup_state(hub: Path, name: str, state: str, note: str = "") -> None:
    if state not in ("done", "waiting"):
        raise AppError("state must be done or waiting")
    if name not in load_lock(hub).apps:
        raise AppError(f"{name} is not installed")
    states = load_state(hub)
    states[name] = {
        "state": state, "note": note, "fingerprint": fingerprint(Path(hub) / "apps" / name),
    }
    save_state(hub, states)


@dataclass
class AppStatus:
    name: str
    version: str
    source: str
    present: bool
    setup: str
    note: str
    missing: list[dict]
    update: bool | None
    min_hub_ok: bool


def _update_available(hub: Path, lock: Lock, name: str, entry: dict) -> bool | None:
    tap_entry = lock.taps.get(entry.get("tap", ""))
    if "link" in entry or tap_entry is None:
        return None
    repo = taps.repo_path(hub, entry["tap"], tap_entry)
    try:
        head = taps.resolve(repo, taps.default_ref(tap_entry))
        if head == entry["commit"]:
            return False
        return bool(taps.changed_files(repo, entry["commit"], head, name))
    except (taps.TapError, gitops.GitError, OSError):
        return None


def app_statuses(hub: Path, *, which=shutil.which) -> list[AppStatus]:
    hub = Path(hub)
    lock = load_lock(hub)
    rows = []
    for name, entry in sorted(lock.apps.items()):
        m = read_installed(hub, name)
        if "link" in entry:
            source = f"link {entry['link']}"
        else:
            source = f"{entry.get('tap')}@{str(entry.get('commit', ''))[:7]}"
        setup, note = setup_status(hub, name) if m else ("pending", "")
        missing = [
            {"name": r.name, "bin": r.bin, "install": r.install_line()}
            for r in (missing_requirements(m, which) if m else [])
        ]
        min_ok = not (m and m.min_hub) or version_tuple(__version__) >= version_tuple(m.min_hub)
        rows.append(AppStatus(
            name, str(entry.get("version", "?")), source, m is not None, setup, note,
            missing, _update_available(hub, lock, name, entry), min_ok,
        ))
    return rows
```

```python
def add_tap(
    hub: Path, source: str, *, name: str | None = None, cwd: Path | None = None
) -> tuple[str, dict, int, str | None]:
    entry = taps.normalize_source(source, cwd=cwd)
    name = check_name(name or taps.default_name(entry), "tap name")
    hub = Path(hub)
    with hub_lock(hub):
        lock = load_lock(hub)
        if name in lock.taps:
            raise AppError(f"a tap named {name!r} is already registered")
        repo = taps.repo_path(hub, name, entry)
        if "url" in entry:
            taps.clone(entry["url"], repo)
        count = len(taps.list_apps(repo, taps.resolve(repo, taps.default_ref(entry))))
        lock.taps[name] = entry
        save_lock(hub, lock)
        warning = gitops.commit_paths(hub, [LOCK_FILE], f"cc-hub: tap add {name}")
    return name, entry, count, warning


def remove_tap(hub: Path, name: str) -> str | None:
    hub = Path(hub)
    with hub_lock(hub):
        lock = load_lock(hub)
        if name not in lock.taps:
            raise AppError(f"no tap named {name!r}")
        users = sorted(a for a, e in lock.apps.items() if e.get("tap") == name)
        if users:
            raise AppError(f"apps installed from {name}: {', '.join(users)}; remove them first")
        entry = lock.taps.pop(name)
        clone = taps.clone_dir(hub, name)
        if "url" in entry and clone.exists():
            rmtree(clone)
        save_lock(hub, lock)
        return gitops.commit_paths(hub, [LOCK_FILE], f"cc-hub: tap remove {name}")


def tap_infos(hub: Path) -> list[dict]:
    lock = load_lock(hub)
    rows = []
    for name, entry in sorted(lock.taps.items()):
        repo = taps.repo_path(hub, name, entry)
        try:
            count = len(taps.list_apps(repo, taps.resolve(repo, taps.default_ref(entry))))
        except (taps.TapError, gitops.GitError, OSError):
            count = 0
        rows.append({"name": name, "source": taps.describe(entry), "apps": count})
    return rows


def search_apps(hub: Path, words: str = "") -> list[dict]:
    lock = load_lock(hub)
    needle = words.casefold().strip()
    rows = []
    for tap, entry in sorted(lock.taps.items()):
        repo = taps.repo_path(hub, tap, entry)
        try:
            commit = taps.resolve(repo, taps.default_ref(entry))
            names = taps.list_apps(repo, commit)
        except (taps.TapError, gitops.GitError, OSError):
            continue
        for app in names:
            try:
                text = taps.read_blob(repo, f"{commit}:{app}/app.toml").decode("utf-8")
                m = parse_manifest(text, dirname=app)
            except (AppError, gitops.GitError, UnicodeDecodeError):
                continue
            if needle and needle not in f"{app} {m.description}".casefold():
                continue
            rows.append({
                "app": f"{tap}/{app}", "version": m.version,
                "description": m.description, "installed": app in lock.apps,
            })
    return rows


STEERING = ("app.toml", "SETUP.md", "REMOVE.md")
STEERING_DIRS = ("skills/", "scripts/", "cron/")


@dataclass
class UpdatePreview:
    name: str
    old: str
    new: str
    changed: list[tuple[str, str]]
    diff: str
    new_requires: list[str]
    local_changes: list[str]
    history_missing: bool
    plan: AppPlan


def local_changes(hub: Path, name: str, repo: Path, commit: str) -> list[str]:
    """Files under apps/<name>/ that differ from the app at `commit`."""
    app_dir = Path(hub) / "apps" / name
    expected = {e.path: e.sha for e in taps.ls_app(repo, commit, name)}
    actual = {p.relative_to(app_dir).as_posix(): p for p in app_dir.rglob("*") if p.is_file()}
    changed = {
        rel for rel, sha in expected.items()
        if rel not in actual or taps.blob_sha(actual[rel].read_bytes()) != sha
    }
    return sorted(changed | (set(actual) - set(expected)))


def preview_update(
    hub: Path, name: str, *, ref: str | None = None, fetch: bool = True
) -> UpdatePreview | None:
    """What `app update` would change, changing nothing; None for a linked app."""
    hub = Path(hub)
    lock = load_lock(hub)
    entry = lock.apps.get(name)
    if entry is None:
        raise AppError(f"{name} is not installed")
    if "link" in entry:
        return None
    source = tap_source(hub, lock, entry["tap"], name, ref, fetch=fetch)
    plan = build_plan(hub, lock, source, replacing=name)
    old, new = entry["commit"], source.commit
    current = read_installed(hub, name)
    old_requires = {r.name for r in current.requires} if current else set()
    history = taps.has_commit(source.repo, old)
    if history:
        changed = taps.changed_files(source.repo, old, new, name)
        steering = [p for _, p in changed if p in STEERING or p.startswith(STEERING_DIRS)]
        diff = taps.diff_text(source.repo, old, new, name, steering)
        app_dir = hub / "apps" / name
        local = local_changes(hub, name, source.repo, old) if app_dir.is_dir() else []
    else:
        changed, diff, local = [("A", p) for p in source.paths()], "", []
    new_requires = [r.name for r in plan.manifest.requires if r.name not in old_requires]
    return UpdatePreview(name, old, new, changed, diff, new_requires, local, not history, plan)


def apply_update(hub: Path, preview: UpdatePreview) -> InstallResult:
    hub = Path(hub)
    name, plan = preview.name, preview.plan
    with hub_lock(hub):
        lock = load_lock(hub)
        entry = lock.apps.get(name)
        if entry is None or entry.get("commit") != preview.old:
            raise AppError(f"{name} changed since the preview; run `cc-hub app update {name}` again")
        app_dir = hub / "apps" / name
        backup = hub / ".cc-hub" / "backups" / "apps" / name / preview.old[:7]
        try:
            if backup.exists():
                rmtree(backup)
            if app_dir.exists():
                shutil.copytree(app_dir, backup)
        except OSError as exc:
            raise AppError(f"backup failed, nothing was changed: {exc}") from exc
        seed_dir = app_dir / "seed"
        old_seed = (
            {p.relative_to(seed_dir).as_posix() for p in seed_dir.rglob("*") if p.is_file()}
            if seed_dir.is_dir() else set()
        )
        retired = _staging(hub, f"{name}-old")
        if app_dir.exists():
            os.rename(app_dir, retired)
        try:
            _materialize(hub, plan.source, app_dir)
        except BaseException:
            if retired.exists():
                os.rename(retired, app_dir)
            raise
        if retired.exists():
            rmtree(retired)
        seeded = _seed(hub, plan, only=set(plan.seed) - old_seed)
        entry.update(commit=preview.new, version=plan.manifest.version)
        save_lock(hub, lock)
        warnings = relink(hub)
        warning = gitops.commit_paths(
            hub, [LOCK_FILE, *seeded],
            f"cc-hub: app update {name} ({preview.old[:7]}..{preview.new[:7]})",
        )
    return InstallResult(
        name, plan.manifest.version, plan.source.describe(), seeded,
        missing_requirements(plan.manifest), warnings + ([warning] if warning else []),
    )


@dataclass
class RemovePlan:
    name: str
    linked: bool
    data_dirs: list[str]
    cron_tasks: list[str]
    software: list[Requirement]
    remove_md: str


def plan_remove(hub: Path, name: str) -> RemovePlan:
    hub = Path(hub)
    entry = load_lock(hub).apps.get(name)
    if entry is None:
        raise AppError(f"{name} is not installed")
    app_dir = hub / "apps" / name
    m = read_installed(hub, name)
    cron = app_dir / "cron"
    tasks = sorted(p.stem for p in cron.glob("*.md")) if cron.is_dir() else []
    remove_md = app_dir / "REMOVE.md"
    return RemovePlan(
        name, "link" in entry, m.data_dirs if m else [], [f"hub:{name}/{t}" for t in tasks],
        m.requires if m else [], read_text(remove_md) if remove_md.is_file() else "",
    )


def apply_remove(hub: Path, name: str) -> list[str]:
    hub = Path(hub)
    with hub_lock(hub):
        lock = load_lock(hub)
        if lock.apps.pop(name, None) is None:
            raise AppError(f"{name} is not installed")
        app_dir = hub / "apps" / name
        if is_link(app_dir):
            remove_link(app_dir)
        elif app_dir.exists():
            rmtree(app_dir)
        save_lock(hub, lock)
        states = load_state(hub)
        if states.pop(name, None) is not None:
            save_state(hub, states)
        warnings = relink(hub)
        warning = gitops.commit_paths(hub, [LOCK_FILE], f"cc-hub: app remove {name}")
    return warnings + ([warning] if warning else [])


@dataclass
class SyncReport:
    restored: list[str] = field(default_factory=list)
    present: list[str] = field(default_factory=list)
    failed: list[tuple[str, str]] = field(default_factory=list)
    strays: list[str] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)


def _restore(hub: Path, lock: Lock, name: str, entry: dict, dest: Path) -> None:
    if "link" in entry:
        src = from_tilde(entry["link"])
        if not src.is_dir():
            raise AppError(f"link source {entry['link']} does not exist on this machine")
        link_dir(src, dest)
        return
    tap_entry = lock.taps.get(entry.get("tap", ""))
    if tap_entry is None:
        raise AppError(f"tap {entry.get('tap')!r} is not registered")
    repo = taps.repo_path(hub, entry["tap"], tap_entry)
    if "url" in tap_entry:
        if not repo.exists():
            taps.clone(tap_entry["url"], repo)
        elif not taps.has_commit(repo, entry["commit"]):
            taps.fetch(repo, tap_entry["url"])
    if not taps.has_commit(repo, entry["commit"]):
        raise AppError(f"commit {entry['commit'][:7]} is no longer in tap {entry['tap']}")
    _materialize(hub, GitSource(entry["tap"], repo, entry["commit"], name), dest)


def sync(hub: Path) -> SyncReport:
    """Make apps/ match apps.lock: restore what is missing, upgrade nothing."""
    hub = Path(hub)
    report = SyncReport()
    with hub_lock(hub):
        lock = load_lock(hub)
        apps_dir = hub / "apps"
        apps_dir.mkdir(exist_ok=True)
        for name, entry in sorted(lock.apps.items()):
            dest = apps_dir / name
            if os.path.lexists(dest):
                report.present.append(name)
                continue
            try:
                _restore(hub, lock, name, entry, dest)
                report.restored.append(name)
            except HUB_ERRORS as exc:
                report.failed.append((name, str(exc)))
        report.strays = sorted(p.name for p in apps_dir.iterdir() if p.name not in lock.apps)
        report.warnings = relink(hub)
    return report
```

```python
# -*- coding: utf-8 -*-
"""cc-hub app: install, set up, update and remove apps from taps."""

from __future__ import annotations

from dataclasses import asdict

import typer

from cc_hub import apps
from cc_hub.console import echo_json, fail, resolve_hub, warn

app_app = typer.Typer(no_args_is_help=True, help="Install and manage apps from taps.")


def _software(reqs: list[apps.Requirement]) -> list[str]:
    return [
        f"  {r.name} ({r.bin}): {r.install_line() or 'no install steps for this platform'}"
        for r in reqs
    ]


def overview(plan: apps.AppPlan) -> list[str]:
    m = plan.manifest
    lines = [f"{m.name} {m.version} from {plan.source.describe()}", m.description]
    lines.append("data dirs: " + (", ".join(m.data_dirs) or "none"))
    lines.append("software:" if m.requires else "software: none")
    lines += _software(m.requires)
    lines.append("scripts: " + (", ".join(plan.scripts) or "none"))
    if plan.crons:
        lines.append("scheduled tasks:")
        for task, cron in sorted(plan.crons.items()):
            kind = "default" if cron["default"] else "optional"
            lines.append(f"  hub:{m.name}/{task}: {cron['schedule']} ({kind}, {cron['session']})")
    else:
        lines.append("scheduled tasks: none")
    lines.append("setup steps: " + ("SETUP.md" if plan.has_setup else "none"))
    lines.append("removal steps: " + ("REMOVE.md" if plan.has_remove else "none"))
    return lines


def _confirm_install(plan: apps.AppPlan, target: str) -> str:
    if isinstance(plan.source, apps.DirSource):
        return f'cc-hub app install "{plan.source.root}" --link --yes'
    return f"cc-hub app install {target} --ref {plan.source.commit} --yes"


def _report(result: apps.InstallResult, hub, verb: str) -> None:
    typer.echo(f"{verb} {result.name} {result.version} ({result.source})")
    if result.seeded:
        typer.echo("seeded: " + ", ".join(result.seeded))
    if result.missing:
        typer.echo("missing software:")
        for line in _software(result.missing):
            typer.echo(line)
    if apps.setup_status(hub, result.name)[0] == "pending":
        typer.echo(f"setup pending: set {result.name} up with the hub-apps skill")
    warn(*result.warnings)


@app_app.command("search")
def search_cmd(
    ctx: typer.Context,
    words: str = typer.Argument("", help="Words to look for in names and descriptions."),
    as_json: bool = typer.Option(False, "--json", help="Machine-readable output."),
) -> None:
    """List apps in the registered taps (no network)."""
    hub = resolve_hub(ctx)
    try:
        rows = apps.search_apps(hub, words)
    except apps.HUB_ERRORS as exc:
        fail(exc)
    if as_json:
        echo_json(rows)
        return
    if not rows:
        typer.echo("no apps found; register a tap with `cc-hub tap add`")
    for row in rows:
        mark = "  (installed)" if row["installed"] else ""
        typer.echo(f"{row['app']}  {row['version']}  {row['description']}{mark}")


@app_app.command("install")
def install_cmd(
    ctx: typer.Context,
    target: str = typer.Argument(..., help="<tap>/<app>, or a directory with --link."),
    ref: str | None = typer.Option(None, "--ref", help="Commit, tag or branch of the tap."),
    link: bool = typer.Option(False, "--link", help="Link a local app directory."),
    yes: bool = typer.Option(False, "--yes", help="Install; without it only print the overview."),
) -> None:
    """Show what an app brings; with --yes, install it."""
    hub = resolve_hub(ctx)
    try:
        plan = apps.plan_install(hub, target, ref=ref, link=link, fetch=not yes)
        if not yes:
            for line in overview(plan):
                typer.echo(line)
            typer.echo("nothing changed yet; to install run:")
            typer.echo(f"  {_confirm_install(plan, target)}")
            return
        result = apps.install(hub, plan)
    except apps.HUB_ERRORS as exc:
        fail(exc)
    _report(result, hub, "installed")


@app_app.command("list")
def list_cmd(
    ctx: typer.Context,
    as_json: bool = typer.Option(False, "--json", help="Machine-readable output."),
) -> None:
    """Installed apps: version, source, setup on this machine, missing software."""
    hub = resolve_hub(ctx)
    try:
        rows = apps.app_statuses(hub)
    except apps.HUB_ERRORS as exc:
        fail(exc)
    if as_json:
        echo_json([asdict(row) for row in rows])
        return
    if not rows:
        typer.echo("no apps installed")
    for row in rows:
        setup = row.setup + (f" ({row.note})" if row.note else "")
        typer.echo(f"{row.name}  {row.version}  {row.source}  setup: {setup}")
        if not row.present:
            typer.echo("  missing from apps/: run `cc-hub app sync`")
        for m in row.missing:
            install = m["install"] or "no install steps for this platform"
            typer.echo(f"  needs {m['name']} ({m['bin']}): {install}")
        if row.update:
            typer.echo(f"  update available: cc-hub app update {row.name}")
        if not row.min_hub_ok:
            typer.echo("  needs a newer cc-hub: uv tool upgrade cc-hub")


def _print_preview(p: apps.UpdatePreview) -> None:
    typer.echo(f"{p.name}: {p.old[:7]} -> {p.new[:7]}")
    if p.history_missing:
        typer.echo(f"  installed commit {p.old[:7]} is no longer in the tap; new files listed")
    typer.echo("changed files:")
    for status, path in p.changed:
        typer.echo(f"  {status} {path}")
    if p.new_requires:
        typer.echo("new software: " + ", ".join(p.new_requires))
    if p.local_changes:
        typer.echo("local changes (kept in the backup): " + ", ".join(p.local_changes))
    if p.diff:
        typer.echo("--- app.toml, SETUP.md, REMOVE.md, skills/, scripts/, cron/ ---")
        typer.echo(p.diff.rstrip())
    typer.echo("nothing changed yet; to update run:")
    typer.echo(f"  cc-hub app update {p.name} --ref {p.new} --yes")


@app_app.command("update")
def update_cmd(
    ctx: typer.Context,
    name: str | None = typer.Argument(None, help="App to update."),
    every: bool = typer.Option(False, "--all", help="Every app installed from a tap."),
    ref: str | None = typer.Option(None, "--ref", help="Commit, tag or branch of the tap."),
    yes: bool = typer.Option(False, "--yes", help="Update; without it only print the changes."),
) -> None:
    """Show what changed in an app's tap; with --yes, update it."""
    hub = resolve_hub(ctx)
    if bool(name) == every:
        fail("name one app, or pass --all")
    if every and ref:
        fail("--ref needs a single app")
    try:
        names = [name] if name else sorted(apps.load_lock(hub).apps)
        for one in names:
            preview = apps.preview_update(hub, one, ref=ref, fetch=not yes)
            if preview is None:
                typer.echo(f"{one}: linked from a local directory; nothing to update")
            elif preview.old == preview.new:
                typer.echo(f"{one} is up to date ({preview.old[:7]})")
            elif not yes:
                _print_preview(preview)
            else:
                _report(apps.apply_update(hub, preview), hub, "updated")
    except apps.HUB_ERRORS as exc:
        fail(exc)


@app_app.command("remove")
def remove_cmd(
    ctx: typer.Context,
    name: str = typer.Argument(..., help="App to remove."),
    yes: bool = typer.Option(False, "--yes", help="Remove; without it only print the plan."),
) -> None:
    """Show what removing an app involves; with --yes, remove it. Its data stays."""
    hub = resolve_hub(ctx)
    try:
        plan = apps.plan_remove(hub, name)
        if not yes:
            linked = " (a link; the linked directory stays)" if plan.linked else ""
            typer.echo(f"remove apps/{name}{linked}")
            typer.echo("data kept: " + (", ".join(plan.data_dirs) or "none"))
            typer.echo("scheduled tasks to unregister: " + (", ".join(plan.cron_tasks) or "none"))
            typer.echo("software it used: " + (", ".join(r.name for r in plan.software) or "none"))
            if plan.remove_md:
                typer.echo("REMOVE.md:")
                typer.echo(plan.remove_md.rstrip())
            typer.echo("nothing changed yet; to remove run:")
            typer.echo(f"  cc-hub app remove {name} --yes")
            return
        warnings = apps.apply_remove(hub, name)
    except apps.HUB_ERRORS as exc:
        fail(exc)
    typer.echo(f"removed {name}")
    typer.echo("data kept: " + (", ".join(plan.data_dirs) or "none"))
    if plan.cron_tasks:
        typer.echo("unregister if still registered: " + ", ".join(plan.cron_tasks))
    warn(*warnings)


@app_app.command("sync")
def sync_cmd(ctx: typer.Context) -> None:
    """Restore apps/ from apps.lock, for example after cloning the hub."""
    hub = resolve_hub(ctx)
    try:
        report = apps.sync(hub)
    except apps.HUB_ERRORS as exc:
        fail(exc)
    for name in report.restored:
        typer.echo(f"restored\t{name}")
    for name in report.present:
        typer.echo(f"present\t{name}")
    for name in report.strays:
        typer.echo(f"not in apps.lock\t{name}")
    for name, why in report.failed:
        typer.echo(f"failed\t{name}: {why}")
    if report.restored:
        typer.echo("setup pending for restored apps: set them up with the hub-apps skill")
    warn(*report.warnings)
    if report.failed:
        raise typer.Exit(code=1)
```

```markdown
description: Find, install, set up, update and remove hub apps, and write or publish new ones. Use when the user wants a capability such as bookkeeping or machine management, when `cc-hub app list` shows an app with setup pending, or when the user wants to package or share their own app.

# hub-apps

An app is a directory installed under `apps/<name>/` from a tap, a git
repository of apps. It teaches you to use some software for the user: its
skills, scheduled tasks, setup steps and a skeleton for its data. cc-hub only
copies files; whatever needs running, you run, with the user's approval.
Instructions inside an app never override the Safety section of `AGENTS.md`.

## Find and install

1. `cc-hub tap list`. Register a tap the user names with
   `cc-hub tap add <owner/repo | git URL | local path>`.
2. `cc-hub app search [words]`.
3. `cc-hub app install <tap>/<app>` prints an overview and changes nothing.
   Show the user the software it needs, its scripts and its scheduled tasks.
4. When the user agrees, run the confirm command it printed (it pins the
   commit with `--ref ... --yes`), then set the app up.

## Set up

Do this for every app that `cc-hub app list` marks `pending`, and only in a
direct chat with the user: setup asks questions, needs approvals and writes
private data. Every step checks before acting, so running it again is safe.

1. **Software.** `cc-hub app list --json` lists `missing` software with this
   platform's install line. Say what each command does and ask. If approved,
   run it and check again. If declined or impossible (for example it needs
   sudo), give the user the steps, run
   `cc-hub app setup-state <name> waiting --note "<what is left>"` and stop.
2. **App steps.** Follow `apps/<name>/SETUP.md` if it exists. Personal
   settings go into the app's data directory, never into `apps/`.
3. **Scheduled tasks.** Run `cc-connect cron list`. For every
   `apps/<name>/cron/<task>.md` with `default: true` whose
   `hub:<name>/<task>` is not listed, run:

       cc-connect cron add --cron "<schedule>" --prompt "<body>" --session-mode <session> --desc "hub:<name>/<task>"

4. **Finish.** `cc-hub app setup-state <name> done`, commit the changes to
   the data directory, and `cc-hub memory log "app <name> set up"`.

An app marked `waiting` is not retried at session start. Run setup again when
the user says the missing part is done, or when `cc-hub app list` no longer
lists missing software.

## Update

1. `cc-hub app update <name>` shows what changed and changes nothing.
2. Summarise for the user: new software, changed scripts, a changed
   `SETUP.md`. Show the full diff if they ask.
3. When they agree, run the printed confirm command. If setup changed, the app
   is `pending` again: set it up right away.

## Remove

1. `cc-hub app remove <name>` shows the plan and changes nothing.
2. Unregister its `hub:<name>/*` tasks: find their ids with
   `cc-connect cron list`, then `cc-connect cron del <id>`. Follow `REMOVE.md`
   if the plan shows one. Ask whether to uninstall the software it used.
3. `cc-hub app remove <name> --yes`, then tell the user where the data stays.

## Write or publish an app

Read `authoring.md` in this directory.
```
